# Scent Blocks

Source code for Scent Blocks prototype, an exploratory research project investigating how olfactory, visual, and auditory cues can support children with Autism Spectrum Disorder (ASD) during transitions between activities.

The project consists of an Arduino-powered multisensory device and a React Native companion application for configuring scents, lights, sounds, and schedules.
